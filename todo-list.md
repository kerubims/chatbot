1. membuat fitur generate karakter yang diintegrasikan oleh ai. ai mencari referensi berdasarkan input yang diberikan oleh user (seperti peran, usia, background story, etc). nantinya dari inputan tersebut, ai akan mencoba meriset karakter yang dimaksud. setelah itu ai akan generate input seperti backstory, greeting message, key memories, current scenario, dan lainnya yang menunjang karakter agar karakter tersebut lebih hidup, setelah itu user bisa melakukan edit manual sesuai keinginan.
2. tombol lampu berfungsi sebagai suggestion chat. karena terkadang user bingung mau menulis apa pada saat roleplay, oleh karena itu user bisa menekan tombol lampu untuk mendapatkan ide chat yang bisa dikirimkan ke ai. fitur ini tidak langsung mengirimkan pesan ke karakter, namun memunculkan pesan di kolom input chat yang bisa di edit terlebih dahulu sebelum dikirimkan ke ai.
3. saya merasa jawaban ai masih banyak mengandung _action_ ketika menjawab. saya ingin ai lebih mengedepankan percakapan dialog antara user dan ai. mungkin dengan komposisi 70% dialog dan 30% action. agar percakapan terasa lebih hidup dan natural.
4. pada halaman chat, saya ingin diberikan tombol translate pesan hasil generate karakter ke bahasa indonesia. namun translate hanya untuk user yang tidak masuk ke prompt yang diberikan oleh user. jadi bahasa default pengiriman pesan ke karakter selalu menggunakan bahasa inggris, jadi tidak mengganggu hasil generate karakter.
